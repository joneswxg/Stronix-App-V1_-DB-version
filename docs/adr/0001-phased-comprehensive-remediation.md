# Phased Comprehensive Remediation

We will remediate the existing Stronix App instead of rewriting it, because the current app already contains valuable local SQLite data flows, exercise assets, theme work, and working training, plan, history, body measurement, and user flows. The remediation will be comprehensive in scope but phased in delivery, ordered by technical risk first and then applied within business areas, so database safety and architecture boundaries are stabilized before broader UI, resource, security, and quality work.
