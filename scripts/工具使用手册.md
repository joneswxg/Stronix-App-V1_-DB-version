# Stronix App 数据库管理工具使用手册

## 概述

本工具集包含两个主要组件：
1. **数据库更新工具** (`db_updater_tool.py`) - 用于批量导入和更新训练动作数据
2. **Web数据库查看器** (`web_db_viewer.py`) - 用于通过浏览器查看和管理数据库内容

## 目录结构

```
scripts/
├── db_updater_tool.py          # 数据库更新工具
├── web_db_viewer.py            # Web数据库查看器
├── templates/                  # Web模板文件
│   ├── base.html
│   ├── index.html
│   ├── actions_select.html
│   └── action_detail.html
└── 使用手册.md                 # 本文件
```

## 1. 数据库更新工具使用说明

### 1.1 功能特性

- ✅ 支持多种文件编码（UTF-8、GBK、CP936、Latin-1）
- ✅ 目标肌肉选择过滤功能
- ✅ 多线程处理，避免界面卡死
- ✅ 智能路径生成（按目标肌肉分类图片）
- ✅ 完整的错误处理和日志输出
- ✅ 数据验证和去重

### 1.2 启动工具

```bash
cd /Users/joneswang/Desktop/Project-Dev/Stronix-App-V1
python scripts/db_updater_tool.py
```

### 1.3 CSV数据格式要求

CSV文件必须包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| `bodyPart` | 身体部位 | waist, chest, upper arms |
| `equipment` | 训练器械 | body weight, dumbbell, barbell |
| `external_id` | 动作外部ID | 1, 107, 466 |
| `name` | 动作中文名称 | 仰卧起坐, 俯卧撑 |
| `name_en` | 动作英文名称 | sit-up, push-up |
| `target` | 目标肌肉 | abs, pectorals, biceps |

### 1.4 使用步骤

1. **选择CSV文件**
   - 点击"浏览..."按钮
   - 选择包含训练动作数据的CSV文件

2. **选择目标肌肉**
   - 从下拉菜单中选择要更新的目标肌肉
   - 选择"所有目标肌肉 (不过滤)"处理所有数据
   - 或选择特定肌肉群（如"腹肌 (abs)"）

3. **开始导入**
   - 点击"开始导入"按钮
   - 工具会在后台处理数据
   - 查看日志输出了解进度

4. **查看结果**
   - 导入完成后会显示统计信息
   - 成功处理的记录数
   - 跳过的记录数及原因

### 1.5 图片路径规则

工具会自动生成图片路径：
- 格式：`Images/{target_muscle}/exercise_{external_id}.gif`
- 示例：`Images/abs/exercise_1.gif`

### 1.6 常见问题

**Q: CSV文件编码错误怎么办？**
A: 工具会自动尝试多种编码格式，如果都失败，请确保文件为UTF-8或GBK编码。

**Q: 某些数据被跳过是什么原因？**
A: 可能的原因：
- bodyPart或equipment在数据库中不存在
- CSV数据格式不正确
- external_id重复

**Q: 如何确认数据导入成功？**
A: 使用Web查看器检查数据库内容，或查看日志中的成功记录数。

## 4. 图片文件管理

### 4.1 目录结构

```
Stronix-App/Resources/Images/
├── abs/                    # 腹肌动作图片
│   ├── exercise_1.gif
│   ├── exercise_2.gif
│   └── ...
├── biceps/                 # 二头肌动作图片
│   ├── exercise_100.gif
│   └── ...
├── pectorals/              # 胸肌动作图片
└── ...                     # 其他目标肌肉文件夹
```

### 4.2 图片命名规则

- 格式：`exercise_{external_id}.gif`
- external_id必须与数据库中的external_id字段一致
- 文件格式推荐使用GIF（动图）

### 4.3 图片放置指南

1. 根据动作的target_muscle将图片放入对应文件夹
2. 确保文件名格式正确
3. 图片大小建议控制在500KB以内
4. 推荐尺寸：300x300像素

## 5. 数据库表结构

### 5.1 主要表说明

- `action` - 训练动作主表
- `target_muscle` - 目标肌肉表
- `body_part` - 身体部位表
- `equipment` - 器械表
- `action_target_muscle_link` - 动作与目标肌肉关联表

### 5.2 重要字段

**action表关键字段：**
- `id` - 主键
- `external_id` - 外部ID（用于图片命名）
- `name` - 中文名称
- `name_en` - 英文名称
- `gifUrl` - 图片路径
- `bodypart_id` - 身体部位ID
- `equipment_id` - 器械ID

## 6. 常见工作流程

### 6.1 新增训练动作数据

1. 准备CSV文件（按目标肌肉分类）
2. 准备对应的动作图片文件
3. 将图片放入对应的目标肌肉文件夹
4. 使用数据库更新工具导入数据
5. 使用Web查看器验证导入结果

### 6.2 更新现有动作数据

1. 选择特定的目标肌肉
2. 准备更新的CSV文件
3. 使用数据库更新工具更新数据
4. 验证更新结果

### 6.3 数据维护

1. 定期使用Web查看器检查数据完整性
2. 检查图片文件是否正确加载
3. 验证动作分类是否准确

## 8. 故障排除

### 8.1 常见错误

**错误：数据库连接失败**
- 检查数据库文件路径是否正确
- 确保有读写权限

**错误：图片无法显示**
- 检查图片文件是否存在
- 验证图片路径是否正确
- 确保图片文件命名符合规范

**错误：CSV解析失败**
- 检查CSV文件编码
- 验证必需列是否存在
- 确认数据格式正确

### 8.2 性能优化

- 单次导入建议不超过1000条记录
- 大批量数据可分批按目标肌肉导入
- 图片文件大小控制在合理范围
